# YomuDoom Privacy Policy

Effective date: August 16, 2026

## Português (Brasil)

### Visão geral

O YomuDoom é um leitor Android gratuito e de código aberto. Os APKs oficiais distribuídos pelo GitHub não incluem Firebase, analytics, telemetria nem envio automático de relatórios de falha. O YomuDoom não exige uma conta própria e não opera servidores para armazenar biblioteca, histórico ou conteúdo de leitura.

### Dados armazenados no aparelho

Biblioteca, histórico, progresso de leitura, preferências, metadados, backups e downloads são armazenados localmente no aparelho ou na pasta de armazenamento escolhida pelo usuário. Esses dados não são enviados ao projeto YomuDoom.

Para excluir os dados internos, use as opções de limpeza do aplicativo ou limpe os dados/desinstale o YomuDoom nas configurações do Android. Downloads, backups e outros arquivos salvos em armazenamento compartilhado podem precisar ser removidos manualmente.

### Serviços externos

O aplicativo acessa a Internet somente para funções solicitadas ou configuradas pelo usuário, incluindo:

- GitHub, para consultar e baixar atualizações do YomuDoom;
- Keiyoushi, para consultar a loja de extensões pré-configurada;
- fontes e provedores selecionados pelo usuário, para pesquisa, metadados e páginas;
- serviços de tracking, somente quando o usuário decide autenticar e sincronizar uma conta;
- Patreon e Stripe, somente quando o usuário abre voluntariamente um link de apoio.

Esses serviços são independentes e podem receber informações técnicas comuns a conexões de Internet, como endereço IP, agente do usuário e dados enviados pelo próprio usuário. O tratamento desses dados segue as políticas de cada serviço. A chave Pix é apenas exibida e copiada localmente; o YomuDoom não processa a transação.

### Permissões

O YomuDoom solicita acesso à rede, notificações, execução de tarefas e uso de bateria em segundo plano para atualizações e downloads. Permissões para consultar, instalar, atualizar ou remover pacotes são usadas para gerenciar extensões Android. O acesso ao armazenamento é usado para downloads, backups e leitura de conteúdo local. As permissões podem variar conforme a versão do Android e os recursos utilizados.

### Crianças, alterações e contato

O YomuDoom não coleta intencionalmente dados pessoais de crianças. Esta política será atualizada se o comportamento de dados do aplicativo mudar. Dúvidas gerais podem ser abertas em [GitHub Issues](https://github.com/YomuDoom/YomuDoom/issues); vulnerabilidades devem ser relatadas de forma privada conforme a [Política de Segurança](./SECURITY.md).

## English

### Overview

YomuDoom is a free and open-source Android reader. Official APKs distributed through GitHub do not include Firebase, analytics, telemetry, or automatic crash reporting. YomuDoom does not require its own account and does not operate servers that store reading libraries, history, or content.

### Data stored on the device

Library entries, history, reading progress, preferences, metadata, backups, and downloads are stored locally on the device or in the storage folder selected by the user. This data is not sent to the YomuDoom project.

To delete internal data, use the cleanup options in the application or clear application data/uninstall YomuDoom through Android settings. Downloads, backups, and other files saved to shared storage may need to be removed manually.

### External services

The application accesses the Internet only for features requested or configured by the user, including:

- GitHub, to check for and download YomuDoom updates;
- Keiyoushi, to query the preconfigured extension store;
- sources and providers selected by the user, for searches, metadata, and pages;
- tracking services, only when the user chooses to authenticate and synchronize an account;
- Patreon and Stripe, only when the user voluntarily opens a support link.

These services are independent and may receive technical information normally included in Internet connections, such as an IP address, user agent, and data submitted by the user. Their own privacy policies govern their processing. The Pix key is only displayed and copied locally; YomuDoom does not process the transaction.

### Permissions

YomuDoom requests network access, notifications, background task execution, and battery usage for updates and downloads. Permissions to query, install, update, or remove packages are used to manage Android extensions. Storage access is used for downloads, backups, and local content. Permissions may vary according to the Android version and features used.

### Children, changes, and contact

YomuDoom does not intentionally collect personal information from children. This policy will be updated if the application's data behavior changes. General questions can be opened in [GitHub Issues](https://github.com/YomuDoom/YomuDoom/issues); vulnerabilities must be reported privately according to the [Security Policy](./SECURITY.md).
