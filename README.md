# YomuDoom

YomuDoom is a personal Android reader for manga, webtoons, comics, and more. It is based on the Mihon open-source project and includes personal changes focused on reading speed, source search, recommendations, and reader controls.

## About This Repository

This repository is the release and project information space for YomuDoom. It is intentionally separate from the application source tree.

It will contain:

- Release notes and patch notes
- Signed APK release assets
- Download and migration information
- Future website content

The application source code is not hosted in this repository.

## Releases

The Releases page will contain the official YomuDoom APKs and the notes shown by the in-app update screen.

Download releases from the [Releases page](https://github.com/Marco-arch/YomuDoom/releases).

## Application Identity

- Display name: `YomuDoom`
- Release package: `app.yomudoom`
- Debug package: `app.yomudoom.dev`
- Minimum Android version: Android 8.0 (API 26)

The package and signing identity must remain stable so Android can install future updates without removing app data.

## Project Status

YomuDoom is under active personal development. Features and release notes may change as the application is tested on real devices.

The repository is currently private staging. Public release access will be enabled when the update channel is ready.
