# Security Policy

## Supported version

Security fixes are provided for the latest YomuDoom release. Before reporting a problem, confirm that it is reproducible on the newest APK published in GitHub Releases.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, leaked credential, malicious extension, or report containing private user data.

Use **Security > Report a vulnerability** in this GitHub repository to submit the report privately. Include the affected YomuDoom version, Android version, reproduction steps, expected impact, and any relevant logs with personal data removed.

The project will acknowledge a valid report through GitHub, investigate it privately, and publish a corrected release and advisory when appropriate. Please do not disclose the issue publicly before a fix is available.

## Scope

The YomuDoom application and its release workflow are in scope. Third-party content providers, extension stores, extensions, tracker services, and Android firmware are independently operated; reports about those systems should be sent to their respective maintainers unless the issue is caused by YomuDoom integration code.
